Fuzz3 quick start
=================

CPU setup
=========

git clone https://github.com/karineek/Fuzz3.git
cd Fuzz3
git checkout gpu_target
chmod +x *.sh library_worker/*.sh library_worker/drivers/*/*.sh SUT/*.sh

./install.sh
source .venv/bin/activate
./install-docker-cloudlab.sh


GPU setup
=========

The GPU path assumes the CloudLab node already has a modern NVIDIA host driver and that nvidia-smi works. Do not install nvidia-driver-470-server for these workers; the CUDA 12.4 Docker images need a newer host driver.

git clone https://github.com/karineek/Fuzz3.git
cd Fuzz3
git checkout gpu_target
chmod +x *.sh library_worker/*.sh library_worker/drivers/*/*.sh SUT/*.sh

./install.sh
source .venv/bin/activate
./install-gpu-cloudlab.sh


GPU runtime checks
==================

nvidia-smi
docker run --rm --gpus all nvidia/cuda:12.4.1-base-ubuntu22.04 nvidia-smi

If Docker permission errors show up after a reboot or new login, run:

sudo chmod 666 /var/run/docker.sock


Build GPU worker images
=======================

DOCKER_BUILDKIT=1 ./library_worker/build-docker.sh gpu thrust
DOCKER_BUILDKIT=1 ./library_worker/build-docker.sh gpu cutlass
DOCKER_BUILDKIT=1 BUILD_JOBS=4 CUDA_ARCHITECTURES=60 CUDA_ARCHITECTURE_TARGETS=6.0 ./library_worker/build-docker.sh gpu arrayfire

ArrayFire is the slow one. On the CloudLab Tesla P100 nodes, the important CUDA settings are CUDA_ARCHITECTURES=60 and CUDA_ARCHITECTURE_TARGETS=6.0.


Smoke test GPU worker images
============================

python3 library_worker/verify_worker.py fuzz3-worker:thrust-gpu --library thrust --gpu
python3 library_worker/verify_worker.py fuzz3-worker:cutlass-gpu --library cutlass --gpu
python3 library_worker/verify_worker.py fuzz3-worker:arrayfire-gpu --library arrayfire --gpu


Create persistent GPU worker containers
=======================================

docker rm -f thrust-gpu cutlass-gpu arrayfire-gpu || true

docker create -i --gpus all --entrypoint python3 --name thrust-gpu fuzz3-worker:thrust-gpu -u /fuzz_workspace/forkserver.py
docker create -i --gpus all --entrypoint python3 --name cutlass-gpu fuzz3-worker:cutlass-gpu -u /fuzz_workspace/forkserver.py
docker create -i --gpus all --entrypoint python3 --name arrayfire-gpu fuzz3-worker:arrayfire-gpu -u /fuzz_workspace/forkserver.py


Run short GPU fuzzing jobs
==========================

FUZZ3_SEEDS=200 FUZZ3_MAX_CHAIN_DEPTH=2 HARNESS_TIMEOUT_SEC=30 HARNESS_MAX_TIMEOUT_SEC=30 ./SUT/fuzz-library-worker.sh /tmp/thrust-seeds /tmp/thrust-out /tmp/thrust-crashes 1000 thrust-gpu thrust all
FUZZ3_SEEDS=200 FUZZ3_MAX_CHAIN_DEPTH=2 HARNESS_TIMEOUT_SEC=30 HARNESS_MAX_TIMEOUT_SEC=30 ./SUT/fuzz-library-worker.sh /tmp/cutlass-seeds /tmp/cutlass-out /tmp/cutlass-crashes 1000 cutlass-gpu cutlass all
FUZZ3_SEEDS=200 FUZZ3_MAX_CHAIN_DEPTH=2 HARNESS_TIMEOUT_SEC=30 HARNESS_MAX_TIMEOUT_SEC=30 ./SUT/fuzz-library-worker.sh /tmp/arrayfire-seeds /tmp/arrayfire-out /tmp/arrayfire-crashes 1000 arrayfire-gpu arrayfire all
