run_latlngolc.bat tcsh script to run all GB postcodes through latlingolc.
With C version of latlingolc takes about an hour. (Assumes can write to /tmp/)

anal_latlngolc.awk
checks run_latlngolc.bat commands and pluscodes generated by latlingolc
Takes about 14 seconds.

Result: 
open_postcode_geo.dat contains multiple repeats
these are faithfully replicated by latlingolc,
so no entropy loss or gain (19.9207 bits)
